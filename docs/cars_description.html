CARS Catalog Dataset Description

This document provides a detailed description of the CARS (CAtalog of Relative Seismic locations) dataset format. The dataset is provided as a comma-separated values (CSV) file, utilizing a semicolon (;) as the delimiter. It contains highly precise, double-difference relocated earthquake hypocenters for the Italian peninsula (1981-2018).

Data Structure and Columns

The dataset contains the following columns, describing the hypocentral parameters, location uncertainties derived from the space-partitioned parametric bootstrap scheme, and quality metrics inherited from the absolute CLASS baseline catalog.

Column Name Description Data Type / Unit
idcars Unique identifier for the relocated event within the CARS catalog. Integer
idclass Unique identifier for the original event in the CLASS baseline catalog (Latorre et al., 2023). This allows for cross-referencing between the absolute and relative locations. Integer
ingvwsid Identifier linking the event to the INGV web services database. A value of 0 may indicate an event lacking a direct mapping in the current web service schema for this specific extraction. Integer
origintime The origin time of the relocated earthquake in UTC (ISO 8601 format: YYYY-MM-DDTHH:MM:SS.sss). String (Datetime)
lat Relocated hypocentral latitude (WGS84). Float (Decimal Degrees)
lon Relocated hypocentral longitude (WGS84). Float (Decimal Degrees)
depth Relocated hypocentral depth below sea level. Float (km)
nccp Number of highly correlated P-wave differential travel-time measurements (cross-correlation data) used in the double-difference relocation. Integer
nccs Number of highly correlated S-wave differential travel-time measurements (cross-correlation data) used in the double-difference relocation. Integer
nctp Number of P-wave differential travel-time measurements derived from catalog phase picks used in the relocation. Integer
ncts Number of S-wave differential travel-time measurements derived from catalog phase picks used in the relocation. Integer
rmscc Root Mean Square (RMS) residual of the cross-correlation differential travel times after relocation. A value of -9.000 indicates no cross-correlation data was used or available for this event (typical for pre-2009 events). Float (seconds)
rmsct Root Mean Square (RMS) residual of the catalog-derived differential travel times after relocation. Float (seconds)
axis_h_max Maximum horizontal error ($E_{H1}$), calculated as the standard deviation of the locations derived from the bootstrap resampling procedure. A value of -9.000 indicates the error could not be robustly estimated. Float (km)
axis_h_min Minimum horizontal error ($E_{H2}$), calculated via the bootstrap resampling procedure. A value of -9.000 indicates the error could not be robustly estimated. Float (km)
axis_v Vertical error ($E_Z$), calculated via the bootstrap resampling procedure. A value of -9.000 indicates the error could not be robustly estimated. Float (km)
bootstrap_gap Maximum azimuthal gap in the station coverage calculated during the bootstrap resampling analysis. Float (degrees)
bootstrap_smp Total number of bootstrap resamplings performed for this event (typically 100). Integer
bootstrap_cfd Confidence level associated with the bootstrap error ellipsoid (e.g., 0.90 for 90% confidence). Float
CLASS_Quality Quality rating assigned to the event in the original CLASS catalog (A: best, to D/E: worst). String (Char)
CLASS_magnitude Magnitude of the event, as reported in the CLASS catalog. May be empty or NaN if unavailable. Float
CLASS_magnitude_type Type or source of the magnitude reported in the CLASS_magnitude column (e.g., CSI1_WEB_MCSTI). May be empty. String

Missing Data Convention

Within the CARS dataset, a placeholder value of -9.000 is systematically used to denote null or undefined numerical values, particularly concerning RMS residuals for absent data types (e.g., rmscc when no waveform correlation data is present) or location error estimates (e.g., axis_h_max, axis_h_min, axis_v) that failed to converge or meet robustness criteria during the bootstrap resampling process.
